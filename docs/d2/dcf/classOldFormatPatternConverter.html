Detailed Description

One-shot conversion of an old-format pattern (.sm2d) to a new file. Never touches the source file – Convert() always writes to a different destination path.

A pattern refers to individual measurements by name inside its formulas. When the measurements file is converted (OldFormatMeasurementsConverter: "@" removed from names, old rint() idiom replaced) the pattern has to be rewritten with exactly the same renames, otherwise it cannot find its measurements any more. So the pattern converter takes the rename map produced by the measurements converter and:

  • replaces every whole-identifier occurrence of a renamed measurement name in every attribute of the file (formulas of points, lines, arcs, curves, increments, ...);
  • rewrites old-style "rint((<expr>)*10^n)/10^n" in those attributes to "rint(<expr>; n)";
  • points the <measurements> element at the converted measurements file (relative path).
