static const QIcon & ReminderRowIcon ()
 ReminderRowIcon a small warning-triangle icon shown in front of the Formula column's text for a "reminder" (rowHighlightReminder) row – see the comment above rowHighlightBlue. Built once into a static QIcon and reused – RefreshTable() rebuilds every row on every change, so this runs often enough to be worth not re-rendering a glyph-to-pixmap every time. Deliberately an icon (QTableWidgetItem::setIcon()), not text prepended to the cell's own string: that string doubles as the "what's actually saved" reference CommitMValueFor() and Fx() compare the edit field against, so anything added there would end up either stuck in the saved formula or breaking that comparison.
