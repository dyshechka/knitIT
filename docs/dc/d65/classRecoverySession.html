Detailed Description

One editing window = one recovery session.

Autosaved copies live in a single central folder (never next to the user's file), so a program crash, a read-only folder or a network drive cannot break them. The session keeps a lock file that the operating system releases automatically when the process dies; another start of the program sees "no owner" and knows the session was abandoned.

Usage: start(); then for every autosave call beginVersion() -> write the document to the returned path -> commitVersion(). Call discard() after the document was saved normally or closed on purpose.
