Detailed Description

The VCheckableActionsComboBox class a combo box whose list is a menu of check boxes of checkable actions.

The box looks exactly like the other combo boxes and always shows the same caption. A click on it opens a menu with the actions (the same look as the list of any combo box on the platform). A click on an item switches the action and the menu stays open, so several items can be ticked in one go.
