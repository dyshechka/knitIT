36/// @brief One-shot conversion of an old-format ("@" required, old rint() idiom) individual
37/// measurements file to a new file in the current format. Never touches the source file --
38/// Convert() always writes to a different destination path.
39///
40/// The rules (agreed with Марта -- see tz_slovar_merok and her "Сконвертировать" request):
41/// - A single leading "@" is removed from every measurement name; "@@" collapses to a single
42/// "@" instead of being removed entirely (so "@@k" -> "@k", "@k" -> "k").
43/// - Every reference to a renamed name inside every OTHER measurement's formula is updated to
44/// match, using whole-identifier-token matching (never a naive text replace) so a rename of
45/// "Р" can never accidentally touch "Рост".
46/// - If stripping "@" from a name would collide with another measurement's name in the same
47/// file, that specific measurement is left untouched (its "@" stays) and a warning is
48/// reported -- the conversion itself is never aborted over a collision.
49/// - Old-style "rint((<expr>) * 10^n) / 10^n" (decimal-place truncation done by hand, via an
50/// outer multiply/divide by a matching power of ten) becomes "rint(<expr>; n)". This is
51/// applied bottom-up, so a nested old-style rint() call inside another one's argument is
52/// converted first. A look-alike that does not divide back by the same value right after the
53/// rint(...) call -- e.g. rounding a percentage for a comparison, "rint(x * 100) > 15" -- is
54/// left exactly as it was, since it isn't decimal-place truncation.
55class OldFormatMeasurementsConverter
56{
57public:
58 struct Report
59 {
60 int renamedCount = 0;
61 int rintConvertedCount = 0;
62 QHash<QString, QString> renameMap; ///< old name -> new name for every renamed measurement; the same
63 ///< map must be applied to a pattern that uses this file
64 ///< (see OldFormatPatternConverter)
65 QStringList collisionWarnings; ///< human-readable, one line per measurement left with its "@"
66 QString errorMessage; ///< non-empty on failure; nothing else in Report is meaningful then
67 };
68
69 static Report Convert(const QString &sourcePath, const QString &destPath);
