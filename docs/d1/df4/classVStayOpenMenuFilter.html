Detailed Description

The VStayOpenMenuFilter class makes a menu stay open when a checkable item is clicked.

Usually a menu closes after every click, so to tick three items it has to be opened three times. Install the filter on a menu and a click (or Enter / Space) on a checkable item only switches the item, the menu stays open until the user clicks somewhere else, on a normal item or presses Escape.
