QString anonymous_namespace{tmainwindow.cpp}::SpreadsheetSafeText ( const QString &  text)

Keeps a spreadsheet (Excel) from "helpfully" reinterpreting a text cell of a CSV file.

Excel turns "(40)" into the number -40, "1-2" into a date, and treats text starting with "=", "+", "-" or "@" as a formula. Such a cell is written as the text formula ="..." (long text is cut into pieces joined with &, since a string literal in a formula is limited to 255 characters), which Excel and other spreadsheets show as exactly the original text. Everything else is returned as is. A plain number (e.g. a formula that is just "40" or "-5") stays a number on purpose.

◆ StripThousandsSpaces()

QString anonymous_namespace{tmainwindow.cpp}::StripThousandsSpaces ( const QString &  formula)

Removes a space used as a thousands separator inside a number: "1 000" -> "1000".

Formulas copied from other sources (e.g. the official Seamly2D samples) sometimes contain such a space, which the formula parser does not accept. Only a space between digits where exactly three digits follow is removed ("1 000", "12 500,5"); spaces around operators and brackets, and digits that belong to a measurement name ("p20 100"), are left alone.
